# Security Policy

Penwash runs locally and binds to `127.0.0.1` by default. It sends text only to your local Ollama instance. Do not expose it to the internet: it has no authentication.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/rokib16x/penwash/security/advisories/new)
rather than a public issue. Expect an initial reply within a week.

## Supported versions

Only the latest release on `main` receives fixes.
